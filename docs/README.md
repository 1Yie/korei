# Documentation map

The root [README](../README.md) is the project entry point. Package READMEs
describe their runtime contracts; code and schemas own exact API signatures and
wire fields.

| Subject                           | Home                                                              |
| --------------------------------- | ----------------------------------------------------------------- |
| Kernel and host integration       | [agent-kernel](../crates/agent-kernel/README.md)                  |
| Current cross-package design      | `docs/design/`                                                    |
| Procedures                        | `docs/guides/`                                                    |
| Exact cross-package facts         | `docs/reference/`                                                 |
| Accepted binding decisions        | `docs/adr/`                                                       |
| Change requests and their results | `docs/proposals/{proposed,implemented,archived}/YYYY-MM-DD-slug/` |
| Dated investigations              | `docs/research/<topic>/`                                          |

Current documents state present behavior. Proposals and research are dated
records. Temporary probes remain outside documentation.
